```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as 몬스터_공격_UI
    participant B as 전투
    participant C as 캐릭터

    User->>UI: 공격버튼클릭()
    activate UI
    
    UI->>B: 몬스터공격(캐릭터)
    activate B
    
    B->>C: 스킬발동()
    activate C
    Note right of C: 다형성에 의해<br/>전사 또는 마법사의 스킬 발동
    C-->>B: 데미지 반환
    deactivate C
    
    B->>B: 등급부여(데미지)
    activate B
    Note right of B: private 메서드 호출로<br/>데미지에 따른 String 등급 산출
    deactivate B
    
    B-->>UI: 공격 결과 및 등급 반환
    deactivate B
    
    UI->>UI: 화면표시()
    UI-->>User: 전투 결과 화면 노출
    deactivate UI
