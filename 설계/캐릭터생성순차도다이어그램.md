```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as Create_Character_UI
    participant B as 전투
    participant P as 플레이어
    participant C as 캐릭터(전사/마법사)
    participant I as 인벤토리

    User->>UI: 캐릭터정보입력(플레이어id, 캐릭터명, 직업, 레벨)
    activate UI
    
    UI->>B: 캐릭터생성(플레이어id, 캐릭터명, 직업, 레벨)
    activate B
    
    B->>P: 플레이어체크(플레이어id)
    activate P
    P-->>B: 검증 결과 반환 (boolean)
    deactivate P
    
    alt 검증 성공 (true)
        B->>C: <<create>> 생성 (이름, 레벨)
        activate C
        Note right of B: 입력받은 직업에 따라<br/>전사 또는 마법사 객체 생성
        
        %% 컴포지션(Composition) 요구사항 반영
        C->>I: <<create>> 생성 (빈 인벤토리 자동 생성)
        activate I
        
        B-->>UI: 캐릭터 생성 성공 응답
        
        UI->>UI: 화면표시()
        UI-->>User: 생성 완료 및 캐릭터 정보 화면 노출
    else 검증 실패 (false)
        B-->>UI: 캐릭터 생성 실패 응답 (권한 없음)
        
        UI->>UI: 화면표시()
        UI-->>User: 에러 메시지 노출
    end
    
    deactivate B
    deactivate C
    deactivate I
    deactivate UI
