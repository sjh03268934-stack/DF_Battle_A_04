``` mermaid
sequenceDiagram
    actor PlayerActor as 플레이어 (Actor)
    participant UI as 길드가입_UI
    participant Ctrl as 전투
    participant PObj as 플레이어
    participant GObj as 길드

    %% 1. 플레이어가 UI를 통해 가입을 요청
    PlayerActor->>UI: 길드 가입 요청 (플레이어id, 길드명)
    activate UI
    
    %% 2. UI는 컨트롤러(전투)에게 조건 검증 및 처리 요청
    UI->>Ctrl: 가입조건검증 요청(플레이어id, 길드명)
    activate Ctrl
    
    %% [필수 조건 1] 플레이어 존재/상태 검증
    Ctrl->>PObj: 플레이어체크(플레이어id)
    activate PObj
    PObj-->>Ctrl: true (정상 플레이어 확인)
    deactivate PObj
    
    %% [필수 조건 2] 길드의 현재 인원수 데이터 조회 (alt 문 실행을 위한 재료 확보)
    Ctrl->>GObj: 현재 인원수 확인()
    activate GObj
    GObj-->>Ctrl: 현재 인원수 반환 (예: 3명)
    deactivate GObj

    %% 3. 제어 클래스(전투)가 수집한 조건을 바탕으로 판단
    alt 조건 충족: [플레이어 정상] AND [현재 인원 < 5]
        
        %% 조건이 충족되었을 때만 실제 가입 메서드 실행 (Aggregation 반영)
        Ctrl->>GObj: 캐릭터가입(character)
        activate GObj
        GObj-->>Ctrl: 가입 완료 (리스트 반영)
        deactivate GObj
        
        %% 컨트롤러가 UI로 결과를 배달
        Ctrl-->>UI: 가입 성공 결과 반환
        UI-->>PlayerActor: 화면 표시 ("길드 가입이 완료되었습니다!")
        
    else 조건 미부합: 정원 초과(인원 >= 5)인 경우
    
        %% 조건이 맞지 않으면 가입을 시키지 않고 실패 결과만 배달
        Ctrl-->>UI: 가입 실패 결과 반환 (정원 초과)
        UI-->>PlayerActor: 화면 표시 ("길드 정원이 가득 차서 가입할 수 없습니다.")
        
    end
    
    deactivate Ctrl
    deactivate UI
