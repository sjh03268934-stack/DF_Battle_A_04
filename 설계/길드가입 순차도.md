``` mermaid
sequenceDiagram
    actor PlayerActor as 플레이어 (Actor)
    participant UI as 길드가입_UI
    participant Ctrl as BattleSystem
    participant PObj as Player
    participant GObj as Guild

    %% 1. 사용자가 UI를 통해 가입 요청 입력
    PlayerActor->>UI: 길드 가입 요청 (inputId, gName)
    activate UI
    
    %% 2. UI가 제어 클래스(BattleSystem)의 joinGuild 메서드 호출
    UI->>Ctrl: joinGuild(inputId, gName)
    activate Ctrl
    
    %% 3. [필수 조건 1] BattleSystem 내부에서 player.checkPlayer(inputId) 실행
    Ctrl->>PObj: checkPlayer(inputId)
    activate PObj
    PObj-->>Ctrl: true (권한 있음)
    deactivate PObj
    
    %% 4. [필수 조건 2] Guild 객체의 addchar 메서드를 호출하여 가입 및 정원 체크 동시 수행
    Ctrl->>GObj: addchar(currentCharacter)
    activate GObj
    
    alt member < 5 (가입 성공 케이스)
        Note over GObj: Gchar.add(Gchar)<br/>member += 1
        GObj-->>Ctrl: true
        Ctrl-->>UI: "길드가입성공" 반환
        UI-->>PlayerActor: 화면 표시 ("길드가입성공")
    else member >= 5 (정원 초과 케이스)
        GObj-->>Ctrl: false
        Ctrl-->>UI: "길드가입실패" 반환
        UI-->>PlayerActor: 화면 표시 ("길드가입실패")
    end
    deactivate GObj
    
    deactivate Ctrl
    deactivate UI
