```mermaid
sequenceDiagram
    autonumber
    actor User as 사용자
    participant UI as Attack_Monster_UI
    participant B as 전투
    participant P as 플레이어
    participant C as 캐릭터(전사/마법사)

    User->>UI: 공격버튼클릭(플레이어id)
    activate UI
    
    UI->>B: 몬스터공격(플레이어id)
    activate B
    
    %% 요구사항: 반드시 플레이어체크를 한다
    B->>P: 플레이어체크(플레이어id)
    activate P
    P-->>B: 검증 결과 (boolean)
    deactivate P
    
    alt 검증 성공 및 캐릭터 존재 시
        B->>C: 스킬발동()
        activate C
        Note right of C: 다형성에 의해<br/>전사 또는 마법사의 스킬 발동
        C-->>B: 데미지 반환
        
        %% 실제 자바 코드에 구현된 스킬명 가져오기 과정
        B->>C: 스킬명반환()
        C-->>B: 스킬명 반환
        deactivate C
        
        B->>B: 등급부여(데미지)
        activate B
        Note right of B: private 메서드 호출로<br/>데미지에 따른 String 등급 산출
        deactivate B
        
        B-->>UI: 공격 결과(스킬명, 데미지, 등급) 문자열 반환
        
        UI->>UI: 화면표시()
        UI-->>User: 전투 결과 및 등급 화면 노출
        
    else 검증 실패 또는 캐릭터 미생성
        B-->>UI: 에러 메시지 반환 (권한 없음 등)
        
        UI->>UI: 화면표시()
        UI-->>User: 에러 발생 알림 노출
    end
    
    deactivate B
    deactivate UI
